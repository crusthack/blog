# 로컬 게임

`/game`의 게임 제목과 상단 바로가기를 누르면 해당 플레이 화면이 즉시 화면 중앙으로 이동한다. URL 해시로 직접 연결할 수 있다.

- `#game-survivor`: 네온 서바이버
- `#game-dino`: BLOCK RUN
- `#game-baseball`: 숫자 야구
- `#game-mines`: 지뢰찾기

## 네온 서바이버

5분 생존형 싱글 플레이 게임. 가까운 적을 자동 공격하며 경험치를 모아 성장한다. 레벨업하면 시간이 멈추고 무작위 능력 3개 중 하나를 선택한다. 이미 최대 단계인 능력은 제외한다.

- 이동: WASD / 방향키 / 터치 이동 패드
- 돌진: Space / 돌진 버튼 (재사용 3초, 짧은 무적)
- 일시정지·재개: P / 화면 버튼
- 성장: 탄환 피해, 공격 속도, 다중 발사, 수호 위성, 범위 충격파, 체력, 이동 속도, 경험치 흡수 범위
- 레벨업 시 체력 일부 회복. 1분마다 등장하는 보스 처치 시 체력 회복과 추가 경험치.
- 시간이 지날수록 적의 등장 빈도와 능력치가 증가한다.

서버 API와 데이터베이스를 사용하지 않는다. 진행 중인 도전과 능력은 메모리에만 있으며 페이지를 나가거나 새로고침하면 초기화된다. 종료한 도전의 최고 생존 시간·처치 수·레벨만 브라우저 `localStorage`의 `blog-survivor-record-v1`에 저장한다. 저장 공간이 차단되어도 게임은 작동한다. 기기 간 동기화는 없다.

플레이 영역에서 포커스를 옮기거나 탭을 전환하거나 화면 밖으로 스크롤하면 자동 일시정지한다. BLOCK RUN도 동일하게 자동 정지하며 게임별 키 입력을 분리한다. 지뢰찾기는 깃발 모드로 터치 조작할 수 있고 첫 칸을 열기 전에 설치한 깃발도 유지한다.

## 검증

`npm run test:frontend`에서 이동 시간 보정, 일시정지, 경험치와 강화 선택, 자동 공격, 보스 보상, 돌진과 피격 무적, 종료 조건, 장시간 개체 수 상한을 검증한다.
