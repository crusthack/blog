# 메인페이지와 개발자소개

- `/`: `apps/frontend/content/home.md`
- `/about`: `apps/frontend/content/about.md`

프런트엔드 Markdown 파일의 frontmatter(`title`, `description`, 선택 사항인 `date`)와 본문을 직접 수정하면 코드 기본값이 바뀐다. 운영에서는 다시 배포한다. 날짜는 `YYYY-MM-DD` 형식이다. 두 파일은 운영 이미지에도 포함된다.

Owner로 로그인하면 각 페이지에 **수정** 버튼이 나타난다. 제목·설명·날짜·Markdown을 편집하고 미리보기를 확인한 뒤 **저장**하면 바로 공개된다. 자동 저장과 초안 단계는 없다. 사이트 관리의 사이트 설정에도 두 페이지로 가는 링크가 있다.

웹 저장 내용은 SQLite의 기존 SiteSettings에 보관하며 코드 파일을 변경하지 않는다. **웹 저장 내용 > 코드 기본값** 순서로 표시한다. 이후 코드 배포가 웹 수정 내용을 덮어쓰지 않는다. **코드 기본값 불러오기**는 편집기에만 복사한다. **코드 기본값으로 복원**은 웹 저장을 해제하여 이후에도 코드 기본값을 따라가게 한다.

API는 `/api/site-pages/home`, `/api/site-pages/about`만 지원한다. 공개 조회는 인증이 필요 없고 PUT 저장·복원은 Owner만 가능하다. revision으로 오래된 화면의 덮어쓰기를 거절한다. 본문은 50,000자, 전체 JSON은 65,536자로 제한한다. 기존 Markdown 렌더러를 사용하여 HTML/스크립트를 실행하지 않는다.

서버에서 콘텐츠를 조회해 페이지와 메타데이터를 함께 렌더링한다. 별도 사이트 설정 로딩 화면은 없다. API 장애 시 코드 기본값을 표시하며 수정은 잠근다. 새로고침 후 재시도할 수 있다. DB 스키마 변경은 없다.
