# 기능 이식 현황과 로드맵

`blog`를 유일한 기준 저장소로 유지하면서 `blog-Frontend`, `blog-Backend`,
`blog-private`에서 검증된 기능을 현재 Next.js + ASP.NET Core 구조에 맞게 선별해
옮긴다. 아래의 **완료**와 **남은 작업**은 2026-09-18 `main` 기준이다.

## 유지할 기준

- 최초 Owner는 일회용 Setup Code로만 생성한다.
- 인증은 ASP.NET Core Identity의 HttpOnly 세션 쿠키를 유지한다.
- 운영 설정과 인증 자료는 환경 변수와 Docker Secret으로만 전달한다.
- Frontend와 Backend는 같은 origin의 `/api/*`로 통신한다.
- 기능 변경은 DB migration, API 통합 테스트, Frontend 테스트·lint·production build를
  함께 통과해야 한다.
- 원본 MDX와 이미지는 보존하고 명시적인 import 과정으로만 이동한다.
- 글과 슬라이드 필기는 자동 저장하지 않고 사용자의 명시적인 저장만 반영한다.

## 완료

### 콘텐츠 탐색과 편집

- 카테고리 생성·수정·숨김·정렬·삭제, 글 연결과 카테고리별 주소.
- 제목·설명 검색, 공개 범위·작성자·북마크 필터, 정렬과 20개 단위 페이지 탐색.
- 작성/나란히/미리보기 편집, Markdown 도구, 미저장 안내와 revision 충돌 거절.
- 계층형 본문 목차, 코드 복사, 읽기 시간, 인쇄와 이전·다음 글 탐색.
- 글 우선순위, 휴지통·복원·영구 삭제와 삭제한 글 번호 재사용 방지.

### 이미지와 첨부 파일

- 글별 JPG/PNG/PDF 저장소와 작성자·Owner 관리 권한.
- 확장자, 실제 파일 형식, 크기와 파일명 검증, 이미지 재인코딩.
- 공개 범위에 따른 다운로드 제어와 PDF 응답 격리.
- DB/실제 파일의 누락·크기 불일치·고아 후보를 확인하는 Owner 점검 화면.
- runtime volume과 배포 전 백업 범위에 첨부 파일 포함.

### 공개 범위와 커뮤니티

- 공개·비공개·코드 보호 글과 본문·댓글·첨부·필기의 일관된 접근 제어.
- 글별 접근 코드 해시, 12시간 HttpOnly 열람 쿠키, 코드·공개 범위 변경 시 무효화.
- 초대 코드 기반 Member 가입, 작성자 권한, 계정 정지와 즉시 세션 차단.
- Markdown 댓글·한 단계 답글, 북마크, 신고 처리와 감사 기록.
- 통합 사이트 관리에서 글·카테고리·회원·신고·초대·설정·상태 관리.

### 슬라이드와 개인 작업 공간

- 제목 기반 자동 분할과 `---` 수동 분할, 전체화면·테마·확대·인쇄·목차.
- 브라우저 IndexedDB의 메모·드로잉·필기 슬라이드와 실행 취소/다시 실행.
- 사용자·글·본문 버전·분할 방식별 격리와 여러 탭의 저장 충돌 거절.
- 로그인 사용자의 서버 저장·불러오기, 기기 간 이동과 저장 내역 관리.

### 운영과 부가 기능

- CI 이후 검증된 commit SHA만 배포하고, runtime 백업·release symlink 전환·health
  검증·실패 시 이전 코드 release 복원.
- 관리자 전용 클라우드의 폴더·파일 관리, 휴지통·복원과 용량 제한.
- 외부 사이트 메뉴와 API·SQLite·배포 버전 상태 화면.
- 서버와 DB를 사용하지 않는 로컬 웹게임 4종.

## 남은 작업

### 1. 콘텐츠 import/export

- `blog-private/posts` frontmatter parser와 dry-run 보고서.
- 폴더 경로를 카테고리로 변환하는 idempotent import.
- 기존 글을 덮어쓰지 않는 충돌 정책과 원본 대비 검증.
- `public/images` 참조 수집, 첨부 이동과 누락 보고.
- 운영자가 선택한 글·첨부를 내보내는 export 형식과 복원 절차.

### 2. 운영 안정성

- DB·첨부·관리자 클라우드의 외부 백업, 보존 정책과 정기 복원 리허설.
- DB migration을 포함한 롤백 전략과 배포 후 데이터 호환성 점검.
- 첨부 및 관리자 클라우드의 확인 후 고아 파일 정리 기능.
- 로그인→작성→댓글→관리 흐름의 실제 브라우저 E2E와 모바일 회귀 테스트.
- 중앙 로그·지표·알림과 부하 시험에 근거한 운영 기준.

### 3. 선택적 제품 확장

- 계층형 카테고리와 카테고리 이동 UX.
- 이메일 확인·계정 복구·MFA/SSO와 조직 단위 권한.
- 고급 인쇄 레이아웃과 이전 본문 버전의 필기 이동 도구.
- 안전한 사용자 정의 MDX 컴포넌트 정책.

## 의도적으로 그대로 옮기지 않는 항목

- 기존 JWT/refresh-token 인증은 현재 세션 쿠키 구조와 중복되므로 이식하지 않는다.
- Owner와 Member 역할 및 초대 가입은 구현했지만, 누구나 가입하는 공개 회원가입은
  운영 정책과 악용 방지 설계 전까지 제공하지 않는다.
- JavaScript/Python playground는 same-origin 코드 실행 위험 때문에 허용 목록 기반
  격리 설계 전에는 복원하지 않는다.
- 자동 저장·자동 병합은 도입하지 않는다. 글은 revision 충돌을 감지하고, 글과
  슬라이드 필기는 사용자가 저장을 선택했을 때만 반영한다.

## 현재 검증 기준

- 프런트엔드 테스트 전체, lint와 production build.
- 백엔드 통합 테스트 전체, format과 EF model/migration 일치 검사.
- Docker Compose와 Nginx 설정 검증, 운영 health check.
