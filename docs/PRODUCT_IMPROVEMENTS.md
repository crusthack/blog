# 블로그 사용성 개선

참고: 사용자가 제공한 `KakaoTalk Downloads/blog/blog`의 개선 로드맵과 인수인계 문서. 해당 폴더는 소스 프로젝트가 아니라 문서·Markdown 자료이며, 현재 프로젝트의 구조에 맞춰 편집 경험을 반영했다.

## 반영 사항

- 작성 / 나란히 / 미리보기 모드, 데스크톱 저장 버튼 고정, 글자·줄 수 표시.
- Markdown 제목, 강조, 링크, 이미지, 목록, 체크리스트, 코드, 인용, 표 도구. 블록 삽입 시 주변 문단과 분리.
- Ctrl/⌘+S로 명시적 저장. 자동 저장이나 초안 저장소는 추가하지 않는다.
- 저장하지 않은 변경 표시. 탭 닫기·새로고침 및 일반 링크 이동에서 확인. 브라우저의 뒤로/앞으로 이동이나 다른 컴포넌트의 프로그램 이동까지 가로채지는 않는다.
- 중복 저장 방지, 기존 글 조회 실패 시 저장 차단, 화면을 밀지 않는 오류 알림.
- 목록 정렬: 최신 글, 오래된 글, 최근 수정, 제목.
- 본문 하단: 현재 위치 링크 복사, 인쇄/PDF, 목록 이동, 맨 위로 이동.

## 후속 후보

슬라이드 작업 공간은 [슬라이드·메모·드로잉](SLIDE_WORKSPACE.md)으로 구현했다. 삭제 복구, 기기 간 서버 저장, 첨부 파일 점검까지 확장했으며 [로드맵 반영 현황](ROADMAP_PROGRESS.md)에 완료 범위와 후속 항목을 기록한다. 계층형 카테고리와 커뮤니티 기능은 후속 후보다. 현재 공개·비공개·코드 보호 정책과 카테고리 포함 주소를 유지한다.
