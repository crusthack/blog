# 게시글 첨부 파일

관리자는 저장된 게시글의 설명·작성일·수정일 아래에서 **파일 첨부·관리**를 열어 파일을 올릴 수 있다. 수정 화면의 첨부 파일 도구도 같은 저장소를 사용한다. 새 글은 먼저 저장한 뒤 첨부한다. 업로드·이름 변경·삭제는 즉시 반영된다.

- 업로드·이름 변경·삭제·관리 목록: Owner만 허용. 일반 회원은 자신이 작성한 글에도 첨부할 수 없다.
- 지원 형식: JPG/JPEG/PNG(10MB), PDF/TXT/MD/CSV/JSON/ZIP/7Z/DOC/DOCX/XLS/XLSX/PPT/PPTX/HWP/HWPX(25MB).
- 이미지는 디코딩·재인코딩하고 PDF 형식을 검증한다. 일반 문서와 압축파일은 서버에서 실행하거나 압축 해제하지 않으며 원본 바이트를 저장한다.
- 첨부 목록은 회색 배경으로 파일명·크기·다운로드 링크를 표시한다. 관리자 이외에는 파일이 없을 때 영역을 숨긴다.
- 다운로드 목록과 파일은 글의 공개 범위·카테고리·코드 인증·휴지통 접근 규칙을 따른다. 파일명도 권한 확인 후에만 제공한다.
- 다운로드 링크의 `?download=1`은 이미지와 PDF도 `Content-Disposition: attachment`로 내려준다. 일반 문서·압축파일은 기존 파일 URL로 접근해도 항상 `application/octet-stream` 첨부 응답을 사용한다. 기존 본문 이미지·PDF 미리보기 URL은 유지된다.

웹 화면뿐 아니라 API에서도 관리자 권한을 검사한다. 기존 파일은 그대로 유지하고 DB migration은 추가하지 않는다. 파일 저장 경로와 운영 백업은 기존 post-assets 설정을 사용한다.
